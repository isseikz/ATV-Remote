## 実装された機能

### 1. ヘルパーアプリケーション (helperApp/)

#### 主要機能
✅ **自動デバイス登録**
- FCMトークン取得
- バックエンドへの自動登録
- デバイス情報の送信

✅ **プッシュ通知受信**
- フォアグラウンドサービスとして常駐

✅ **APKダウンロード**
- S3署名付きURLから取得

- キャッシュ領域への保存

✅ **インストール処理**
- FileProviderを使用
- システムダイアログ表示
- 権限管理UI

✅ **ビルド履歴管理**
- Compose UIで表示
- ブランチ、コミット、バージョン情報
- インストール状態追跡

#### 技術スタック
- Kotlin
- Jetpack Compose (Material 3)
- Firebase Cloud Messaging
- Ktor Client
- Coroutines & Flow
- kotlinx.serialization

### 2. バックエンドサーバー拡張 (demo/server/installer/)

#### 提供API
✅ **デバイス登録**
```
POST /api/devices/register
```
- FCMトークン保存
- デバイス情報管理
- 登録時刻記録

✅ **ビルド通知ウェブフック**
```
POST /api/builds/notify
```
- S3パス情報受信
- 署名付きURL生成
- FCM一斉配信

✅ **デバイス一覧**
```
GET /api/devices
```
- 登録済みデバイス取得
- デバイス数確認

✅ **ヘルスチェック**
```
GET /api/health
```
- サービス稼働状況
- デバイス登録数

#### サービス実装
- **DeviceRegistry**: デバイス管理（インメモリ）
- **FcmNotificationService**: FCM送信（Firebase Admin SDK）
- **S3PresignedUrlService**: AWS S3 URL生成（2時間有効期限）

## 制限事項

### 現在の制限
1. **ビルド環境**: サンドボックス環境ではGoogle Maven Repositoryアクセス制限のためビルド不可。標準開発環境では問題なし。

2. **デバイス登録**: 現在はインメモリ。本番環境ではデータベース推奨。

3. **サイレントインストール**: Androidセキュリティ仕様により不可。ユーザー確認必須。

4. **初回セットアップ**: ヘルパーアプリ自体は手動インストール必須。

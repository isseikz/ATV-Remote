# Launcher Icons

The launcher icons for the helper app should be placed in the following directories:

- `mipmap-mdpi/ic_launcher.png` (48x48)
- `mipmap-hdpi/ic_launcher.png` (72x72)
- `mipmap-xhdpi/ic_launcher.png` (96x96)
- `mipmap-xxhdpi/ic_launcher.png` (144x144)
- `mipmap-xxxhdpi/ic_launcher.png` (192x192)

And round icons:

- `mipmap-mdpi/ic_launcher_round.png` (48x48)
- `mipmap-hdpi/ic_launcher_round.png` (72x72)
- `mipmap-xhdpi/ic_launcher_round.png` (96x96)
- `mipmap-xxhdpi/ic_launcher_round.png` (144x144)
- `mipmap-xxxhdpi/ic_launcher_round.png` (192x192)

## Temporary Workaround

For development, you can use Android Studio's built-in icon generator or copy icons from the demo app.

## Icon Design Guidelines

The icon should visually represent:
- Helper/installation functionality
- Android TV remote connection
- Development/testing context

Consider using:
- Package/box icon with download arrow
- Android robot with tools
- Remote control with badge
